허용되는 형식:
label: 한줄요약

label 종류:

| label    | 설명                                                      |
| -------- | --------------------------------------------------------- |
| feat     | 기능 추가                                                 |
| fix      | 기능 수정                                                 |
| docs     | 문서 생성, 수정, 삭제, 주석                               |
| style    | 줄바꿈, 띄어쓰기, 네이밍                                  |
| refactor | 기능은 동일 코드 구조가 바뀜                              |
| build    | 종속성 변경, 도커, DB, 인프라                             |
| front    | 프론트 생성, 삭제, 수정                                   |
| chore    | hooks 설정, README 수정 등 위의 유형에 해당하지 않는 것들 |
