# 🕹️ CrewOn (크루온)

> 나와 잘 맞는 팀원을 보다 수월하게 찾고, 함께 문제를 해결해나가며 쌓아올린 경험을 시각적으로 녹여내 나의 이력으로 기록하는 플랫폼

프로그래머스 백엔드 데브코스 최종 프로젝트 5팀 Team Arcade입니다.

## 프로젝트 소개

### 문제 정의

- 공개 모집만으로는 어떤 지원자가 올지 알기 어렵고, 서로 알아가려면 1:1로 연락을 주고받아야 해 과정이 길고 피로하다.
- 프로젝트를 진행하고 나면 과정을 정리·기록해야 하는데, 매일 직접 남기기는 쉽지 않다.
- 이력서처럼 형식이 정해진 문서로는 노력의 과정을 증명하기 어렵고, 노션·일기장·투두앱에 흩어진 기록은 공유하기 힘들다.
- 결과물을 만들고 나서 사용자 반응이나 피드백을 받을 곳이 마땅치 않다.

크루온은 이 네 가지를 **팀원 모집 → 활동 기록 자동화 → 결과물 전시**라는 하나의 흐름으로 묶어 해결한다.

### 목표 사용자

IT 종사자 및 IT 업계 희망자를 대상으로 한다.

- 같은 관심사를 가진 팀원을 구하는 사람
- 개인 이력 관리를 편하게 하고 싶은 사람
- 노력의 결과를 홍보하고 싶은 사람
- 대회 정보를 한 곳에서 보고 싶은 사람
- 대회(해커톤·공모전)를 운영하는 주최측(정식 사업자)

### 차별점

- **자동 이력 관리**: 서비스 안에서 파티원을 구하고 활동을 이어가면 기록이 자동으로 쌓이고, 별도 등록 절차 없이 마이페이지에 반영된다.
- **선순환 구조**: 매칭 → 파티 모집 완료 → PR 기록 → 결과물 전시·성취 자동기록 → 마이페이지 이력 기반 재매칭으로 이어진다.
- **정교한 검색**: 빈 포지션 현황을 실시간으로 보여주고, 형태소 분석 + 동의어/유사어 사전으로 놓치기 쉬운 파티까지 찾아준다.
- **개인화 파티 추천**: 프로필·성취 키워드와 파티 설명 키워드를 매칭해 정렬하고, LLM이 상위 후보를 이유와 함께 큐레이션한다.

## 핵심 기능

- **파티 모집**: 포지션(백엔드/프론트엔드/UIUX/PM)별 정원 지정, 대회·프로젝트·스터디·기타 주제 유형, 모집 기한 D-day 표시, 지원·승인, 파티장의 수동 모집 마감
- **검색**: Nori 형태소 분석기로 키워드를 추출·정규화하고, 동의어 사전으로 검색 범위를 넓힌다
- **대회(공모전·해커톤)**: 관리자 CRUD, 파티와 연결, 모집 기한이 지난 글은 자동 정리
- **성취 프로필**: 자기신고(수상·경력·TODO) + 플랫폼 인증(파티 확정·완료 시 성취 자동 생성·달성), 스트릭 배지, 연도·카테고리·태그 필터링
- **매칭 히스토리 & 알림**: 지원 승인·접수·모집 마감·파티 완료·전시 게시를 SSE로 실시간 알림
- **GitHub PR 연동**: GitHub App 설치·OAuth로 저장소를 연결하고, 웹훅 + SSE로 PR 현황을 실시간 동기화
- **쪽지**: 발신자·수신자·내용·읽음 여부로 구성된 비동기 1:1 메시지함
- **파티 추천**: 검색 데이터·스킬·포지션·성취 이력을 바탕으로 LLM이 큐레이션한 파티를 파티 게시판에서 바로 보여준다
- **마이페이지**: 프로필·관리(지원 현황)·성취 리스트·참여 파티 히스토리·쪽지·북마크를 한 화면에서 관리하는 개인 대시보드

## 기술 스택

| 구분 | 내용 |
| --- | --- |
| 백엔드 | Java 25 · Spring Boot 4.1 · Spring Data JPA |
| 프론트엔드 | Next.js(React) · TypeScript — 디자인 토큰 기반 다크/라이트 테마, ESLint·tsc 검사를 CI에 포함 |
| 데이터베이스 | PostgreSQL — Full Text Search + Nori 형태소분석(GIN 인덱스) |
| 캐시 · 실시간 | Redis(JWT Refresh 저장·회전, 재사용 탐지) · SSE(PR 스트림, 개인 알림) |
| AI 연동 | Google Gemini API — 파티 추천 큐레이션(후보 랭킹 + 추천 이유 생성) |
| 인프라 · 배포 | Docker Compose · Nginx · Terraform · GHCR · GitHub Actions |
| 서버 자원 | AWS EC2 단일 인스턴스 — 앱 · DB · 캐시 · 모니터링을 컨테이너로 함께 운영 |
| 개발 환경 | 팀원 개인 노트북(macOS · Windows WSL2) — 동일 Docker Compose 구성으로 로컬 환경 통일 |
| 협업 도구 | GitHub(이슈 · PR 리뷰) · Linear(스프린트 · ARC 이슈 추적) · Notion · Discord |

버전 등 상세 근거는 [기술 스택 상세](docs/tech-stack.md) 문서 참고.
